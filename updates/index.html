v2.0.0

26 May 2022

Summary

Replaced Jekyll with Hugo as our static site generator.

New Features

  • Presidium CLI tool that allows you to scaffold new sites from a template.
  • A new Presidium Hugo Theme that replaces the default Jekyll theme.
