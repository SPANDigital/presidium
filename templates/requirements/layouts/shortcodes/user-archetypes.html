{{/* user-archetypes Description: Renders the archetypes from the current page's frontmatter as a grammatically correct list with links to their corresponding archetype detail pages. Used in user stories to display "As a [archetype]" with proper linking. Usage: {{< user-archetypes >}} Parameters: None - reads archetypes from the current page's frontmatter Context: - Requires page to have "archetypes" in frontmatter (array of strings) - Links to pages where frontmatter "archetype" field matches the value - Falls back to plain text if no matching archetype page is found Example frontmatter: --- archetypes: - "content consumer" - "article author" --- Example output: Single: a content consumer Multiple: a content consumer, or a article author */}} {{- $archetypes := .Page.Params.archetypes -}} {{- if $archetypes -}} {{- range $i, $archetype := $archetypes -}} {{- $page := first 1 (where $.Site.Pages "Params.archetype" $archetype) -}} {{- if $i -}}, or a {{ end -}} {{- if $page -}} {{ $archetype }} {{- else -}} {{ $archetype }} {{- end -}} {{- end -}} {{- else -}} [archetype] {{- end -}}
